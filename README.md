## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/tk857021-lab/CS50X.git
   ```
2. Open the folder in a code editor such as VS Code.
3. **C programs:** compile and run, for example:
   ```bash
   gcc mario.c -o mario
   ./mario
   ```
4. **Python programs:**
   ```bash
   python week6/mario.py
   ```
5. **SQL queries:** run the `.sql` files with SQLite against the course databases.
6. **Websites:** open the `.html` file in your browser.
7. **Flask apps (Birthdays, Finance):**
   ```bash
   cd week9/finance
   pip install -r requirements.txt
   flask run
   ```
